# Система управления задачами с приоритетами

Командный проект по дисциплине «Основы программирования», вариант 1. Консольная программа на Python для ведения списка задач с приоритетами, дедлайнами, фильтрацией и историей просмотров.

## Авторы и зоны ответственности

| Участник | Файлы | За что отвечает |
|----------|-------|-----------------|
| Участник 1 | `task.py`, `storage.py`, `main.py` | модель данных, хранилище, сохранение в JSON, меню и каркас программы |
| Участник 2 | `bst.py`, `queue_module.py`, `undo.py` | бинарное дерево поиска, очередь, стек отмены действий |
| Участник 3 | `filters.py`, `history.py` | фильтрация, сортировка, сохраненные фильтры, история просмотров |

## Как запустить

Нужен Python 3.8 или новее. Сторонние библиотеки не требуются.

```
python main.py
```

Программа покажет меню и будет ждать ввода номера команды. Состояние хранится в `data/state.json` и подхватывается при следующем запуске.

## Реализованные функции

Основное задание:

- [x] ведение списка задач (название, приоритет, время выполнения, дедлайн)
- [x] стек отмены последних действий (добавление, удаление, изменение)
- [x] очередь задач на исполнение
- [x] бинарное дерево поиска по дедлайнам
- [x] вывод задач по возрастанию дедлайна рекурсивным обходом
- [x] быстрый поиск задачи с самым ранним и самым поздним дедлайном

Дополнительный функционал:

- [x] фильтр по шести условиям (статус, категория, приоритет, дедлайн, ключевое слово, время)
- [x] сортировка результата встроенной sorted по четырем полям
- [x] сохранение фильтров под именем и вызов одной командой
- [x] переименование и удаление сохраненных фильтров
- [x] история просмотров на двух стеках с командами назад и вперед

## Структура проекта

```
task-manager/
  main.py            меню и главный цикл
  task.py            класс Task и хранилище задач
  storage.py         сохранение и загрузка JSON
  bst.py             бинарное дерево поиска по дедлайнам
  queue_module.py    очередь на исполнение
  undo.py            стек отмены и откат действий
  filters.py         фильтрация, сортировка, сохраненные фильтры
  history.py         история просмотров на двух стеках
  data/state.json    сохраненное состояние
  tests/             юнит-тесты
```

## Тесты

Из корня проекта:

```
python -m unittest discover -s tests
```
