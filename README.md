# Менеджер задач

Консольная программа для ведения списка задач. У каждой задачи есть название, приоритет, время выполнения, дедлайн, статус и категория. Программа умеет добавлять, удалять и менять задачи с откатом последнего действия, держит очередь задач на исполнение, строит дерево задач по дедлайну и показывает их по возрастанию срока, а также ищет задачи по условиям, сортирует найденное, сохраняет частые фильтры под именами и листает недавние результаты поиска назад и вперед.

## Что умеет программа

- Добавление, удаление и изменение задач
- Отмена последнего действия командой `undo`, откатываются добавление, удаление и изменение
- Очередь задач на исполнение, задачу можно поставить в очередь и затем исполнить
- Дерево задач по дедлайну, вывод всех задач по возрастанию срока рекурсивным обходом
- Быстрый поиск задачи с самым ранним и самым поздним дедлайном по дереву
- Фильтр задач по статусу, категории, приоритету от и до, дедлайну от и до, ключевому слову в названии и времени выполнения
- Сортировка найденных задач по дедлайну, приоритету, времени или названию
- Сохранение частых фильтров под именем, вызов одной командой, переименование и удаление
- История просмотров на двух стеках, недавние результаты фильтрации листаются командами `back` и `forward`

## Структуры данных

- Стек (`Stack`) для отмены последних действий пользователя
- Стек используется еще дважды внутри истории просмотров, один стек хранит результаты позади, второй впереди
- Очередь (`Queue`) для задач на исполнение, задачи берутся в том порядке, в котором поставлены
- Бинарное дерево поиска (`BST`) по дедлайну. Ключ узла это дедлайн, в узле лежит список задач с этим дедлайном, поэтому одинаковые сроки не теряются. Симметричный обход дает задачи по возрастанию дедлайна, спуск до конца влево дает самый ранний срок, до конца вправо самый поздний
- Словари для быстрого поиска задачи по ее номеру и для именованных фильтров
- Встроенная сортировка `sorted` для вывода найденных задач по выбранному полю

## Структура проекта

- `structures.py` хранит классы структур данных `Stack`, `Queue`, `Node`, `BST`
- `manager.py` хранит класс `TaskManager`, модель задачи и проверку полей, в классе собраны добавление, удаление, изменение, отмена и работа с очередью
- `filters.py` хранит поиск задач, сортировку, именованные фильтры и историю просмотров
- `main.py` хранит ввод команд, диалоги и главный цикл программы

## Запуск и команды

При старте программа спрашивает, загрузить ли демонстрационные задачи. Если ответить д, в список добавляется несколько готовых задач, на которых удобно проверить все команды. Если ответить н, список остается пустым.

- `add` добавить задачу, программа по очереди спросит все поля
- `del <id>` удалить задачу по номеру
- `edit <id>` изменить одно поле задачи
- `list` показать все задачи по возрастанию дедлайна
- `early` показать задачу с самым ранним дедлайном
- `late` показать задачу с самым поздним дедлайном
- `enqueue <id>` поставить задачу в очередь на исполнение
- `next` исполнить следующую задачу из очереди, ее статус станет выполнена
- `queue` показать очередь на исполнение
- `undo` отменить последнее действие
- `find` найти задачи по условиям, программа спросит условия и поле сортировки
- `save <имя>` сохранить последний фильтр под именем
- `run <имя>` выполнить сохраненный фильтр
- `saved` показать список сохраненных фильтров
- `rename <старое> <новое>` переименовать сохраненный фильтр
- `drop <имя>` удалить сохраненный фильтр
- `back` показать предыдущий результат поиска
- `forward` показать следующий результат поиска
- `help` показать список команд
- `quit` выход

Приоритет задается числом от 1 до 5, где 5 это самый важный. Время выполнения задается в минутах. Дедлайн вводится строкой вида ГГГГ-ММ-ДД, например 2026-06-15, такие строки сравниваются между собой как даты. Статус может быть новая, в работе или выполнена. В фильтре пустой ответ значит, что условие не используется.

## Как устроен код

Класс `Stack` это стек на списке с методами `push`, `pop`, `is_empty`. На нем держится отмена действий, а также обе половины истории просмотров.

Класс `Queue` это очередь с методами `enqueue`, `dequeue`, `remove`, `to_list`. В нее попадают номера задач, которые пользователь хочет исполнить.

Классы `Node` и `BST` это узел и бинарное дерево поиска по дедлайну. Метод `insert` добавляет задачу, при совпадении дедлайна задача кладется в список того же узла. Метод `in_order` симметричным обходом собирает задачи по возрастанию срока, методы `earliest` и `latest` спускаются по дереву до края и дают самый ранний и самый поздний дедлайн. Метод `rebuild` строит дерево заново по списку задач, это проще, чем удалять отдельные узлы.

Модуль `manager.py` отвечает за сами задачи. Класс `TaskManager` держит список задач, поиск по номеру, дерево, очередь и стек отмены прямо в своих полях. Функция `build_task` проверяет поля и собирает задачу, `valid_date` проверяет формат дедлайна. Методы `add`, `delete` и `edit` меняют список и дерево и кладут запись о действии в стек отмены. Метод `undo` достает последнюю запись и откатывает действие. Методы `enqueue` и `run_next` работают с очередью на исполнение, а `ordered`, `earliest` и `latest` обращаются к дереву.

Модуль `filters.py` отвечает за поиск. Функция `matches` проверяет одну задачу по всем заданным условиям, `run_filter` оставляет подходящие задачи и сортирует их по выбранному полю. Класс `SavedQueries` хранит фильтры по именам и умеет их сохранять, отдавать, переименовывать и удалять. Класс `ViewHistory` держит историю просмотров на двух стеках, метод `add` запоминает новый результат, методы `go_back` и `go_forward` листают историю назад и вперед.

Модуль `main.py` связывает все вместе. Функция `main` создает менеджер, сохраненные фильтры и историю, при старте предлагает демонстрационные задачи и запускает главный цикл. Цикл читает команду и передает ее в `handle_task_command` или `handle_query_command`, а диалоги вроде `add_dialog` и `find_dialog` по очереди спрашивают нужные значения и проверяют ввод.

## Над проектом работали

### 1

- Класс `Stack` с методами `push`, `pop`, `is_empty` (`structures.py`)
- Класс `Queue` с методами `enqueue`, `dequeue`, `remove`, `to_list` (`structures.py`)
- Классы `Node` и `BST`, методы `insert`, `rebuild`, `in_order`, `earliest`, `latest` (`structures.py`)
- Команды `list`, `early`, `late`, `enqueue`, `next`, `queue` в `handle_task_command` (`main.py`)

### 2

- Модель задачи, проверка полей `build_task`, `valid_date` (`manager.py`)
- Класс `TaskManager`, методы `add`, `delete`, `edit` (`manager.py`)
- Отмена действий `undo` и работа с очередью `enqueue`, `run_next` (`manager.py`)
- Диалоги `add_dialog`, `edit_dialog` и команды `add`, `del`, `edit`, `undo` (`main.py`)

### 3

- Фильтрация `matches`, `run_filter` и описание фильтра `describe` (`filters.py`)
- Именованные фильтры `SavedQueries` и история просмотров `ViewHistory` (`filters.py`)
- Поиск `find_dialog`, показ результатов и `handle_query_command` (`main.py`)
- Главный цикл `main`, демонстрационные задачи и список команд (`main.py`)
